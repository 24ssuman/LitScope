# Workspace Instructions

- Keep all created or modified files inside the current working directory.
- If temporary files are needed, create them under `./tmp/`.
- Do not delete files in the working directory unless explicitly specified.
- Maintain `PLAN.md` for the implementation plan.
- Maintain `LOG.md` with timestamped notes for each step, including what changed and why.
- Make sure project folders have a `README.md` before finishing.
